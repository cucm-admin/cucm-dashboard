# 🌐 Cisco CUCM IPT 통합 관제 전광판 (NOC Wallboard & C8300 E1 Inspector)

실시간 Cisco 음성 인프라(CUCM 클러스터, Voice Gateway, SME, C8300 라우터 및 E1 트렁크) 통합 관제 및 장애 대응 시뮬레이션 대시보드입니다.

---

## 🚀 주요 기능

1. **실시간 트래픽 및 상태 KPI 모니터링**
   - 전사 실시간 Call 건수, 트렁크 가동 현황, CPS(Call Per Second), MOS 음질 점수 실시간 계측
   - 김포 센터 / 여의도 센터 부하 분산율 동적 표시

2. **지능형 다이어그램 & 인터랙티브 토폴로지**
   - 국선 PSTN/ISP ↔ 음성 게이트웨이(VG) ↔ SME(Session Management Edition) ↔ 지사/내선 간 연결 구조 가시화
   - 트렁크 상태(UP / DOWN / WARNING)에 따른 광선 파티클 애니메이션 및 색상 반응형 피드백
   - 노드 드래그 앤 드롭 재배치 및 레이아웃 자동 저장(LocalStorage)

3. **Cisco Catalyst 8300 (C8300) 섀시 & E1 포트 인스펙터**
   - 김포/여의도 랙별 C8300-1N-4T-2X 라우터 섀시 그래픽 뷰
   - NIM-8MFT-T1/E1 모듈 포트(RJ48)별 가동 상태, 활성 B-Channel(채널 점유율/30ch), 통신사(KT, LGU+, SKB) 상태 모니터링
   - 클릭 시 Cisco IOS-XE 포트 상세 진단(ISDN Q.921/Q.931 레이어, BER, 슬립 카운터, 루프백 진단 등) 드로어 제공

4. **실시간 시나리오 시뮬레이터 & 오디오 알람**
   - **정상 운용**: 14/14 트렁크 안정적 로드밸런싱
   - **피크 트래픽 폭주**: 2,400+ Calls 돌파 및 고부하 경고 차임벨
   - **여의도 센터 ISP 장애**: 여의도 VG 트렁크 DOWN 감지 및 김포 센터로 즉각 우회(Failover)
   - **홍콩 지사 SIP 트렁크 단선**: 해외 지사 단선 경보 및 경로 격리

5. **NOC 전광판 최적화 모드**
   - 4K/FHD 대형 모니터 맞춤형 반응형 레이아웃
   - 사이버펑크 네온 다크 테마 / 하이 콘트라스트 모드 지원
   - 전체화면 토글(F11 / 버튼) 및 1초 주기 실시간 시계

## 💻 사용 방법

### 1. 웹 브라우저에서 바로 실행 (GitHub Pages)
- 설치 과정 없이 웹 브라우저(Chrome, Edge 등)에서 바로 열람 가능합니다.

```bash

```
